# TAG OK - Tu Copiloto Digital en Autopistas Urbanas
**TAG OK** es una aplicación móvil multiplataforma diseñada para centralizar y gestionar de forma inteligente los cobros de las autopistas urbanas en Santiago de Chile. El proyecto nace como respuesta a la fragmentación de información entre concesionarias y la falta de visibilidad del gasto en tiempo real que enfrentan los conductores.
## 🚀 Problemática y Solución
### El Problema
 * **Información Fragmentada:** Los datos de cobros residen en múltiples plataformas independientes.
 * **Cero Visibilidad:** Los usuarios no conocen su gasto acumulado hasta el final del mes.
 * **Decisiones "a ciegas":** Falta de herramientas para evaluar si el costo de una ruta en horario punta justifica el ahorro de tiempo.
### Nuestra Solución
TAG OK actúa como un monitor inteligente que ofrece:
 * **Mapa Interactivo:** Visualización de rutas y pórticos en tiempo real.
 * **Calculadora de Viajes:** Estimación precisa de peajes basada en horarios y tarifas dinámicas.
 * **Control Presupuestario:** Sistema de alertas preventivas y bitácora de gastos por patente.
## 🛠️ Especificaciones Técnicas
El proyecto se construye bajo una **Arquitectura Modular** y escalable:
 * **Frontend:** Desarrollado con **Flutter y Dart**, utilizando el patrón **MVVM** y **Riverpod** para una gestión de estado robusta.
 * **Backend (PaaS):** Integración con **Firebase** (Authentication para usuarios y Cloud Firestore para la base de datos NoSQL).
 * **Integraciones (SaaS):** * **TollGuru API:** Para el cálculo inteligente de peajes.
   * **Mapbox SDK:** Para cartografía avanzada y ruteo.
 * **Herramientas:** GitHub para control de versiones y Postman para testing de APIs.
